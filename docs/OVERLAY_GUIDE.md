# BPSRAssist — คู่มือการใช้งาน Game Overlay

> 🌐 ภาษา: [ไทย](OVERLAY_GUIDE.md) | [English](OVERLAY_GUIDE.en.md)

**Game Overlay** คือหน้าต่างโปร่งใสที่โปรแกรมแสดงซ้อนทับอยู่บนหน้าต่างเกม เพื่อแสดงข้อมูลช่วยเล่น เช่น DPS Meter, Minimap, สถานะบัฟ/เดบัฟ, ตัวจับเวลามอนสเตอร์ ฯลฯ โดยไม่ต้องสลับหน้าต่างออกจากเกม

> หมายเหตุ: คีย์ลัด ตัวเลือก และหน้าจอในคู่มือนี้ อ้างอิงจากเวอร์ชันปัจจุบันของโค้ด ค่าที่เป็น **ค่าเริ่มต้น (Default)** จะระบุไว้ในวงเล็บ

## 1. เปิดใช้งาน Overlay

1. เปิดหน้า **Game Overlay** ในตัวแอป แล้วเปิดสวิตช์ **Enable Overlay** *(ค่าเริ่มต้น: เปิด)*
2. เปิดเกมผ่านตัวเปิดเกมของแอป (หรือรอให้แอปจับหน้าต่างเกมได้) — Overlay จะถูกสร้างขึ้นมาเองอัตโนมัติเมื่อเกมกำลังรัน
3. Overlay จะแสดงเฉพาะตอนที่ **หน้าต่างเกมเป็นจอที่โฟกัสอยู่** เท่านั้น ถ้าสลับไปหน้าต่างอื่นหรือเดสก์ท็อป Overlay จะหายไปเอง

ตัวเลือกหลักในหน้านี้:

| ตัวเลือก | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| **Enable Overlay** | On | เปิด/ปิดใช้ Overlay ทั้งระบบ |
| **Auto-hide Overlay** | On | ซ่อน Overlay อัตโนมัติเมื่อไม่อยู่ในหน้าจอเล่นเกมหลัก (เช่น กำลังโหลดฉาก หรืออยู่หน้า UI/เมนูของเกมที่เคอร์เซอร์เมาส์แสดงอยู่) แต่จะไม่ซ่อนระหว่างจบดันเจี้ยน / ตกปลา / ขณะกด `Alt` ค้าง |
| **Use Subform Overlay** | Off | ฝัง Overlay เข้าไปในหน้าต่างเกมโดยตรง (เป็น child window) แทนการวางเป็นหน้าต่างแยกซ้อนทับ |

## 2. โหมดแก้ไข (Edit Mode) — ปลดล็อกเพื่อจัดเรียง

ขณะเล่นปกติ Overlay จะ "ล็อก" อยู่เพื่อกันคลิกโดนโดยไม่ตั้งใจ เมื่อต้องการย้าย/ปรับขนาด widget ให้ปลดล็อกก่อน:

1. กดคีย์ลัด **`ALT + 1`** *(ค่าเริ่มต้น — เปลี่ยนได้ที่การ์ด Toggle Overlay Lock ในหน้า Game Overlay)*
2. จะเห็น **แถบควบคุม (Control Bar)** ปรากฏกลางบนจอ และ widget ทุกตัวจะมีกรอบ + ปุ่มจัดการขึ้นมา (อยู่ในโหมดแก้ไข)

**การออกจากโหมดแก้ไข** (ทำได้ 3 ทาง แล้วตำแหน่งทั้งหมดจะถูกบันทึกอัตโนมัติ):

- กดคีย์ลัด `ALT + 1` อีกครั้ง
- **คลิกพื้นที่ว่าง** บนจอ (ที่ไม่ใช่ widget)
- สลับไปหน้าต่างอื่นเกิน ~2 วินาที (ออกจากโหมดให้อัตโนมัติ)

![ภาพ: โหมดแก้ไข Overlay (Edit Mode)](images/edit-mode-control-bar.png)

**การจัดเรียง widget ในโหมดแก้ไข:**

- **ลาก** widget ไปวางตรงไหนก็ได้ โดยมีระบบช่วยจัดตำแหน่ง (Snap):
  - ติดขอบจอ / กึ่งกลางจอ → เส้นนำฟ้า (cyan)
  - จัดแนวกับ widget อื่น → เส้นนำส้ม
  - ติดกริด (Grid Snap)
- **ปรับขนาด** โดยลากที่มุมหรือขอบทั้ง 8 จุดของ widget
- ตำแหน่ง/ขนาดจะ **บันทึกทันที** เมื่อปล่อยเมาส์ และบันทึกอีกครั้งตอนออกจากโหมดแก้ไข

## 3. จัดการ Widget แต่ละตัว

### 3.1 เมนู Widgets (เปิด/ปิด widget ทุกตัว)

กดปุ่ม **☰ (Widget Menu)** ที่ Control Bar จะเห็นรายชื่อ widget ทั้งหมด ใช้สวิตช์หรือกดที่ชื่อเพื่อเปิด/ปิดแต่ละตัว และกดรูปเข็มหมุด 📌 เพื่อปักหมุดไว้ที่แถบ

![ภาพ: เมนู Widgets](images/widget-menu.png)

### 3.2 ปุ่มจัดการบน widget (ตอนอยู่ในโหมดแก้ไข)

เมื่อชี้/อยู่ในโหมดแก้ไข จะมีปุ่มปรากฏที่มุม widget:

- **⚙️ Settings** — เปิดแผงตั้งค่าของ widget ตัวนั้น (ดูข้อ 3.3)
- **Click-through** — สลับให้เมาส์ "ทะลุ" widget นี้ไปโดนเกม (เหมาะกับ widget แบบแสดงผลอย่างเดียว เช่น Minimap)
- **📌 Pin** — ปักหมุด/เอาปุ่มลัดของ widget นี้ออกจาก Control Bar
- **✕ Close** — ปิด (Disable) widget ตัวนั้น
- **ปุ่มดินสอ (FAB)** มุมขวาล่าง — เปิดเมนู **Manage** ด่วนของ widget (เช่น DPS Meter: สลับโหมด DPS/Healing/Tanking และจำนวนแถว) — จะโผล่เฉพาะ widget ที่มีเมนูนี้ และเฉพาะตอนเอาเมาส์ชี้

![ภาพ: ปุ่มจัดการบน widget](images/widget-manage-buttons.png)

### 3.3 แผงตั้งค่า (⚙️) ของแต่ละ widget

แผงตั้งค่าจะมีส่วนกลางเหมือนกันทุกตัว:

- **Show Headers** — แสดงแถบหัวข้อด้านบนของ widget หรือไม่
- **Visible In States** — เลือกสถานะเกมที่อยากให้ widget นี้แสดง (🧭 Explore / ⚔️ Combat / 🏆 Dungeon End / 🎣 Fishing / 🌐 Always)
- **Background Opacity** — ปรับความทึบของพื้นหลัง widget

ด้านล่างของแผงจะเป็น **ตัวเลือกเฉพาะของ widget นั้นๆ** เช่น:

- DPS Meter: Show Ranks, Show Class Icons, Show Imagines, ระยะเวลาซ้อมกับหุ่น (Training Duration), เป้าหมาย Dummy ฯลฯ
- Minimap: ขนาด/สีของจุดผู้เล่น-ทีม-บอส, Lock Direction, โหมดวงกลม ฯลฯ

![ภาพ: แผงตั้งค่า widget](images/widget-settings-flyout.png)

## 4. แถบควบคุม (Control Bar) และ Layout Presets

Control Bar (เห็นเฉพาะในโหมดแก้ไข) ประกอบด้วย (จากซ้ายไปขวา):

1. **รูป avatar** ของตัวละคร
2. **ปุ่ม ☰** — เปิดเมนู Widgets (ข้อ 3.1)
3. **ปุ่มไอคอน widget** — กดเพื่อเปิด/ปิด widget นั้นอย่างรวดเร็ว (ปุ่มสว่าง = เปิดอยู่; ตัวที่ปักหมุด 📌 ไว้จะยังโผล่แม้ปิด widget)
4. **นาฬิกา**
5. **ปุ่ม ⚙️ (Settings ของ Overlay)** — ประกอบด้วย:
   - **Widget layout → Reset** — คืนตำแหน่ง widget ทั้งหมดกลับเป็นค่าเริ่มต้น (ปุ่มไอคอนรีเซ็ต)
   - **Layout Presets** — เซฟ / โหลด / ลบชุดเลย์เอาต์ทั้งหน้า (พิมพ์ชื่อในช่อง แล้วกดปุ่ม เซฟสีเขียว / โหลดสีฟ้า / ลบสีแดง) เหมาะกับสลับเลย์เอาต์หลายแบบ เช่น แบบตอนฟาร์ม กับแบบตอนตีบอส

![ภาพ: แผง Settings ของ Control Bar (Reset ตำแหน่ง + Layout Presets)](images/layout-presets.png)

## 5. การคลิก / โต้ตอบ Widget ระหว่างเล่น

- Widget ส่วนใหญ่ (Minimap, Buffs/Debuffs Monitor, Stats Monitor, Notification ฯลฯ) ตั้งค่าเป็น **Click-through** = เมาส์จะทะลุ widget ไปโดนเกมตามปกติ ไม่รบกวนการเล่น
- Widget ที่ **ปิด Click-through** ไว้ (เช่น DPS Meter, Skill Log, Spawn Tracker, Clock, Game Tasks) จะคลิก/ใช้งานได้โดย **กด `Alt` ค้างไว้ + ชี้เมาส์** ที่ widget นั้น (เช่น กดปุ่มรีเซ็ตข้อมูลบนหัว DPS Meter) — พอปล่อย `Alt` ก็กลับเป็นทะลุเมาส์เหมือนเดิม

> เคล็ดลับ: ถ้าเล่นแล้วรู้สึกว่า widget "บังเมาส์" ให้เปิด Click-through ให้ widget ตัวนั้น (ในโหมดแก้ไข → ปุ่มรูปเมาส์) หรือถ้าอยากคลิกได้โดยไม่ต้องกด Alt ค้าง ก็ปิด Click-through ทิ้งได้ตามความถนัด

## 6. คีย์ลัดเสริม (Custom Keybinds)

หน้า **Game Overlay → Keybinds** กดปุ่ม **Add Keybind** เพื่อเพิ่มคีย์ลัดใหม่ จากนั้นเลือก **Keybind Action** และกด **Record Keybind** เพื่อจับชุดคีย์ (ตอนกำลังจด กล่องจะขึ้น `RECORDING...` แดงพัลส์)

คีย์ลัดที่มีให้ใช้:

| Action | คำอธิบาย |
|---|---|
| **DPS Meter - Display Type** | สลับค่าที่แสดงบนมิเตอร์ DPS / HPS / DTPS *(ค่าเริ่มต้น: `CTRL + ALT + 1`)* |
| **DPS Meter - Display Limit** | สลับจำนวนแถวที่แสดง (5 / 10 / 15 / 20) |
| **DPS Meter - Capture** | คัดลอกภาพ DPS Meter ไปยัง Clipboard (มีข้อความแจ้ง "Captured!") |
| **Game Tasks - Start/Stop** | เริ่ม/หยุด Game Task ที่เลือกอยู่ (เช่น Auto Fishing / Auto Gathering) |
| **Auto Switch Line - Next / Previous** | สลับช่อง (Channel Line) ไปข้างหน้าหรือข้างหลัง |

ในรายการแต่ละแถวยังมีสวิตช์เปิด/ปิดคีย์ลัด และปุ่มถังขยะสำหรับลบได้ทันที

## 7. รายชื่อ Widget ทั้งหมด

Widget มีทั้งหมด **15 ตัว** โดยค่าเริ่มต้นจะมีเฉพาะ **DPS Meter** และ **Notifications** ที่เปิดอยู่ ตัวอื่นต้องไปเปิดเองที่เมนู ☰ หรือ Control Bar

| Widget | หน้าที่ | สถานะเริ่มต้น |
|---|---|---|
| **DPS Meter** | มิเตอร์สถิติปาร์ตี้/เดี่ยว — DPS / Healing / Tanking พร้อมอันดับในปาร์ตี้ | เปิด — แสดงใน Explore, Combat, Dungeon End |
| **Skill Log** | บันทึก/แสดงสกิลที่ใช้ตามเวลา | ปิด |
| **Skill Breakdown** | แยกสัดส่วนความเสียหายตามสกิล | ปิด |
| **Spawn Tracker** | ตัวจับเวลาการเกิดของมอนสเตอร์ | ปิด |
| **Nearby Players** | รายชื่อผู้เล่นที่อยู่ใกล้เคียง | ปิด |
| **Buff Tracker** | ติดตามบัฟของตัวเอง (แสดงเฉพาะตอนต่อสู้) | ปิด |
| **Stats Monitor** | แสดงค่าสถานะตัวละคร (โจมตี, คริ, Haste, Luck ฯลฯ) | ปิด |
| **Buffs Monitor** | แสดงบัฟที่กำลังมีอยู่ | ปิด |
| **Debuffs Monitor** | แสดงเดบัฟที่ติดตัวอยู่ | ปิด |
| **Minimap** | มินิแมปแสดงตำแหน่งตัวเอง/ทีม/บอส/มาร์กเกอร์ | ปิด |
| **Boss DBM** | แจ้งเตือน/ไทม์ไลน์สกิลบอส | ปิด |
| **Game Tasks** | ปุ่มและสถานะของ Game Task (Auto ตกปลา/เก็บของ ฯลฯ) | ปิด |
| **Clock** | นาฬิกาแสดงเวลาจริง | ปิด |
| **Performance** | แสดง FPS / CPU / GPU / RAM | ปิด — แสดงตลอดเวลา (Always) |
| **Notifications** | แจ้งเตือนจากโปรแกรม (เช่น DPS ถูกคัดลอกแล้ว) | เปิด |

## 8. ข้อควรรู้เพิ่มเติม

- **การบันทึก**: ตำแหน่ง ขนาด การเปิด/ปิด และการตั้งค่าของ widget ทั้งหมดจะถูกบันทึกอัตโนมัติ (เก็บในไฟล์ `config.yaml` ข้างตัวโปรแกรม) และโหลดกลับมาใหม่ทุกครั้งที่เริ่มเกมรอบใหม่
- **คีย์ลัดทำงานเมื่อใด**: คีย์ลัดทั้งหมด (รวมถึง `ALT + 1`) จะทำงานเฉพาะตอนที่เปิดเกม/Overlay อยู่เท่านั้น — ถ้ากดแล้วไม่มีอะไรเกิดขึ้น ให้เช็คว่าเกมกำลังรันอยู่ และ Enable Overlay เปิดอยู่
- **DPI / เปลี่ยนจอ**: เมื่อ DPI หรือตำแหน่งหน้าต่างเกมเปลี่ยน โปรแกรมจะคำนวณตำแหน่ง Overlay ใหม่ให้อัตโนมัติ ตำแหน่ง widget ถูกเก็บเป็นสัดส่วน (%) ของหน้าจอเกม จึงไม่เพี้ยนเมื่อเปลี่ยนความละเอียด
- **โหมด Subform**: ถ้าเปิด **Use Subform Overlay** ต้องใช้กับหน้าต่างเกมแบบที่รองรับการฝัง child window การสลับเปิด/ปิดโหมดนี้ระหว่างเล่นจะสร้าง Overlay ใหม่ให้อัตโนมัติ
